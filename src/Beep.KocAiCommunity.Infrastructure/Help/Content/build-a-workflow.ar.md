# مسارات العمل

مسار العمل رسم بياني صغير: **مجموعة بيانات ← تحويلات ← تقسيم ← تدريب ← تقييم**.

1. ابدأ من **قالب للنفط والغاز** (عطل مضخة ESP، معدّل الإنتاج، سحنات سجلات الآبار) أو من لوحة فارغة.
2. احفظ **مسودة**. المسودات قابلة للتعديل.
3. **انشر** لتجميد إصدار ثابت ببصمة لقطة. والنشر يشغّل المُصرِّف **وفحص التقسيم قبل التدريب** — فأي
   نموذج كان سيُدرَّب على البيانات كاملة (تدريب + اختبار) يُرفض منعًا لتسرّب البيانات.
4. **صدّر واستورد** مسار العمل كملف JSON محمول.

بعد النشر لا يتغيّر الإصدار أبدًا؛ وأي تعديل تالٍ يفتح مسودة جديدة.
